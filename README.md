# Jogo Sem Saída

**Projeto de Aplicações Front-End**

## Sobre o projeto

O Sem Saída é um jogo desenvolvido em JavaScript, HTML e CSS, inspirado no clássico Pac-Man. O jogador controla um ladrão que precisa percorrer um labirinto, coletando sacos de dinheiro e evitando ser capturado pelos policiais.

## Objetivo do jogo

Coletar todos os sacos de dinheiro do labirinto, acumular pontos e avançar pelas fases, evitando os policiais que perseguem o personagem.

## Regras do jogo

- O jogador controla o ladrão utilizando o teclado.
- O objetivo é coletar os sacos de dinheiro espalhados pelo labirinto.
- Os policiais perseguem o ladrão, e uma captura resulta na perda de uma vida.
- O jogador começa com três vidas.
- As bombas podem ser utilizadas para desorientar temporariamente os policiais.
- Maletas de bônus podem aparecer durante a partida e conceder pontos extras.
- Ao perder todas as vidas, o jogo termina, permitindo reiniciar a partida.
- Ao coletar todos os sacos de dinheiro, o jogador pode avançar para a próxima fase.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar o jogo

**Para jogar online:** acesse o link do GitHub Pages disponibilizado pelo projeto.

**Para executar localmente:**
1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso estejam compactados.
3. Abra o arquivo `index.html` em um navegador.
